Section backups from the shop/brand split (2026-04-17).

- `merch-section.backup.html` — the full `#merch` section extracted from the
  original unified `shop/index.html`. The live version still exists at
  [shop/index.html](../shop/index.html).
- `variants-section.backup.html` — the `#variants` section (lockups).
  The live version is at [brand/index.html](../brand/index.html).
- `system-section.backup.html` — the `#system` section (palette, typography,
  voice rules). The live version is at [brand/index.html](../brand/index.html).

These are HTML fragments, not standalone pages — they won't render correctly
on their own. They exist as a safety net; every change is also preserved in
git history.
